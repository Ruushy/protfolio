Hacker by mindset, engineer by training

I take systems apart to understand exactly how they fail, then use that knowledge to defend them. My core work is web application penetration testing and network security: reconnaissance, vulnerability assessment, exploitation, and clear reports that help teams fix what is actually broken.

I am also a full-stack developer, and that sharpens my security work. I build with Django, Python, and the MERN stack, so I know how authentication, APIs, and business logic break from the inside, and how to write code that holds up.

I turn both skills into tools and teaching: security scanners, recon frameworks, hands-on vulnerability labs, and five Somali-language books on cybersecurity, networking, SQL injection, XSS, and Nmap.
