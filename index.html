§01SummaryField notes

I work both sides of the same wall: building software with one hand, and trying to break it with the other. Every system I ship gets stress-tested by someone who already knows where engineers hide their assumptions — because that someone is me.

Day to day that means full-stack delivery across the MERN stack and Django — database to interface — alongside web penetration testing, network hardening, and OSINT reconnaissance. I don't just use these skills, I package them into hands-on labs so other people in Somalia can learn them too.

That's also why I write. I'm the author of five technical books in Somali covering networking and offensive security — because the best security education in the world doesn't help anyone if it never arrives in their own language.
